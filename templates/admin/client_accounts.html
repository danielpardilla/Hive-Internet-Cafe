How it works:

  • Any-PC Account: allows login from any workstation
  • Customer logs in with their name & password
  • Names are case-insensitive (first name match OK)
  • Create same account on multiple PCs for PC-specific multi-location access
  • Deactivate accounts when no longer needed
Tip: Leave PC empty for flexible access (one account, any PC). Assign to PC for restricted access (one account per location).
